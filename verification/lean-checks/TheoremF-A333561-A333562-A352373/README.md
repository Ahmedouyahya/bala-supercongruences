# Machine check of Theorem F (p ≥ 5) and of A333561, A333562, A352373

Result: Theorem F of `proofs/TheoremF-p-ge-5.md` is proved in Lean for all integers a, b and all c ≥ 0: for every prime p ≥ 5 and M ≥ 1, A(pM) ≡ A(M) mod p^(3(1+v_p(M))), where A(N) = [x^{cN}] ((1+x)^a (1−x)^b)^N. From it, Bala's conjectures on A333561, A333562 and A352373, in the form of the benchmark targets `oeis_333561_conjecture`, `oeis_333562_conjecture_0_congruence` and `oeis_a352373_supercongruence`, are proved and accepted by every check below. Checked on 2026-10-16.

Earlier claims: rbajaj5's unreviewed drafts claimed the cubic tower for this family for p ≥ 5 before this work (A352373 and A333562 named, A333561 as a case of the family; `literature/PRIOR-CLAIMS.md`). These Lean proofs are an independent, machine-checked proof of previously claimed results.

## The proof (namespace `TF`)

The Lean proof follows the paper, on top of the power-series exponential of Epoch AI's accepted A333042 proof (`EpochExp.lean`, see Files). φ^N is defined as exp(N·(a·log(1+x) + b·log(1−x))), which makes the paper's Lemma 1 a coefficient identity, and the alternating harmonic sum is handled by H_T^± = H_T − H_{T/2}.

| Lean declaration | Statement | Paper step |
|---|---|---|
| `expS_lp`, `expS_lm`, `expS_neg_lm`, `expS_neg_lp`, `pint_Phi` | exp(log(1±x)) = 1±X and the inverses; φ^N has p-integral coefficients | set-up |
| `frob_F`, `Phi_pM` | p·F = expand_p F + p·L (p odd); φ^{pM} = expand_p(φ^M)·exp(pM·L) | Lemma 1 |
| `A_sub` | A(pM) − A(M) = Σ_{w<cM} ε_{p(cM−w)}·γ_w | (1) |
| `alt_sum`, `H_bound`, `Hpm_bound` | H_T^± = H_T − H_{T/2}; v_p(H_T) ≥ 2v_p(T) (via Epoch's `H_law`); same for H_T^± (T even) | Lemmas 2, 3 |
| `coeff_L_sq`, `V_coeff_L_sq` | the coefficient formula for L² at T ≡ 0 mod p; v_p([x^T]L²) ≥ v_p(T) | Lemma 4 |
| `pint_L`, `eps_bound` | v_p(ε_T) ≥ min(2r + v_p(T), 3r) | (2) |
| `cong_pow_p`, `frob_full`, `frob_iter`, `lemma6` | Frobenius lifting; v_p(γ_s) ≥ r − 1 − v_p(s) | Lemmas 5, 6 |
| `theoremF`, `tower_int` | Theorem F; the tower for any sequence equal to A on N ≥ 1 | §4 |
| `A_m_neg_one`, `A_neg_one_neg_three`, `A333562.a_eq_rep` | the target formulas as coefficients: A333561 = A(3,−1,2), A333562 = A(4,−1,3) (after the identity Σ_{j≤3n} C(n+j−1,j)2^j = Σ_k C(4n,3n−k)C(n+k−1,k), proved with a Zeilberger certificate), A352373 = A(−1,−3,1) | §5 |

## A333561 for the OEIS definition

The OEIS defines A333561 by a(n) = Σ_{j=0..2n} C(n+j−1, j)·2^j, while the benchmark target uses the equivalent formula Σ_{k≤2n} C(3n, 2n−k)·C(n+k−1, k). The congruence is therefore also proved for the OEIS definition itself: `A333561Oeis.aOEIS_supercongruence` (`fc-workspace/BalaCheck/A333561Oeis.lean`), with the two formulas linked by `BinomIdent.S_eq_R` (the identity Σ_{j≤K} C(m+j,j)·2^j = Σ_{k≤K} C(m+1+K, K−k)·C(m+k,k), proved with a Zeilberger certificate; copied from `A333562Ident.lean` into a module that imports no target). `#print axioms` gives the standard three for both; lean4checker exit 0 on both modules (`outputs/A333561-oeis-definition-audit.txt`).
