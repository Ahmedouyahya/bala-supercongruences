## The proof

1. Bridge (namespace `A333565`, `A333565Bridge.lean`): with B(n) = Σ_{k≤n} C(2n,n−k)·C(n+k−1,k) (= A119259), `A333565_eq`: (A333565 n : ℤ) = 2·B(n) − (−1)^n, so the target's `toNat` changes nothing (B(n) ≥ 1). Proof by Pascal's rule: B(n) + B(n−1) = 2^n·C(2n,n) − 2^n·C(2n−2,n−2), and the target's convolution satisfies e(n) + e(n−1) = 2^n C(2n,n) + 4·2^(n−1) C(2n−2,n−1) (`B_add`, `e_add`, `e_eq`). `A333565_diff`: for N, M of the same parity, A333565(N) − A333565(M) = 2(B(N) − B(M)).
2. p ≥ 5: B = A(2,−1,1) (`TF.A_m_neg_one 2 1`) and Theorem F (`TF.tower_int`); see `verification/lean-checks/TheoremF-A333561-A333562-A352373/`.
3. p = 3 (Theorem F₃(ii) of `proofs/TheoremF-p-eq-3.md` for (a,b,c) = (2,−1,1); modules `TF3Harm`, `TF3G`, `TF3Exp`, `TF3Main`):
