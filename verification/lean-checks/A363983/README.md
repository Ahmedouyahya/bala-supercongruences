# Machine check of A363983

Result: Bala's conjecture on A363983, in the form of the benchmark target `oeis_A363983_conjecture_supercongruence` (all primes p ≥ 5, all n, r ≥ 1, modulus p^(3r)), is proved in Lean and accepted by every check below. Checked on 2026-10-16.

The target applies `Int.toNat` to an alternating sum, so the proof first shows that the sum is positive for n ≥ 1 (from its P-recurrence, proved with a Zeilberger certificate); `toNat` then changes nothing.

## The proof

| Lean declaration | Statement | Paper step (`proofs/A363983.md`) |
|---|---|---|
| `A363983.cert`, `poly_id`, `rec_s` | certificate identity (one polynomial identity checked by `ring`), giving c0(n)s(n) + c1(n)s(n+1) + c2(n)s(n+2) = 0 for the target's sum s | non-negativity |
| `s_pos`, `cast_A363983` | s(n+1) ≥ 7 s(n) > 0, hence `(A363983 n : ℤ) = s n` for n ≥ 1 | non-negativity |
| `OSS.kaz_int` | p^(v(C(A,B))+3+v(A)+v(B)+v(A−B)) ∣ C(pA,pB) − C(A,B) for p ≥ 5, from `Epoch361883.JAC_bound` | Lemma 1 (Kazandzidis) |
| `OSS.half_lower`, `half_upper`, `block_sum`, `inv_sq_blocks` | sums of k⁻² over blocks and half-blocks of units vanish mod p^s | Lemma 2 |
| `OSS.lemma3_int`, `lemma3_pred_int`, `lemma4i_int`, `lemma4i_pred_int`, `lemma4ii_int` | the binomial congruences mod p^r | Lemmas 3, 4 |
| `A363983.T_scaled_int` | p^(3+3v(M)) ∣ T(pM,pK) − T(M,K) for every K | Lemma 5 |
| `T_unscaled`, `D_level`, `S_dvd`, `G0_dvd` | factorisation of the unscaled terms, self-similar kernel, level induction (`OSS.level_sum`), p^(3r) ∣ unscaled sum | (2), (3), Lemma 6 |
| `s_cong` | p^(3r) ∣ s(mp^r) − s(mp^(r−1)) | theorem |

The proof does not assume p ∤ m: Lemma 5 is proved for every scaled index with modulus p^(3+3v(M)).

`OSS` (`lean/BalaProofs/OSSLib.lean`) is a sequence-independent library written for this entry and reused by later ones; besides the lemmas above it contains the generic level induction `level_sum_blocks` (any weight whose block sums vanish, any self-similar kernel).
