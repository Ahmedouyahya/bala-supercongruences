## (4) CITATION AUDIT

**Colmez, Th. I.4.7 (PDF p. 15, rendered and read):** "Les [n/p^h]! (x choose n) pour n ∈ N forment une base orthonormale de LA_h(Z_p, L)." Standing conventions: v_p(p) = 1; L any closed subfield of C_p; B(a,r) = {x ∈ C_p : v_p(x−a) ≥ r}; LA_h(Z_p, L) = functions whose restriction to a+p^hZ_p is the restriction of an L-analytic function on B(a,h), with v_{LA_h}(φ) = inf_a v_{B(a,h)}(φ_{a,h}); **Rem. I.4.4**: φ(x) = Σ a_k(φ,a)((x−a)/p^h)^k and v_{LA_h}(φ) = inf_{a∈S} inf_k v_p(a_k(φ,a)); **Prop. I.4.3**: v_{B(a,r)}(φ) = inf_{x∈B(a,r)} v_p(φ(x)) (so LA_h-convergence implies uniform convergence); **Déf. I.1.3**: orthonormal basis = unique convergent expansion with a_i → 0 and v_B(x) = inf v_p(a_i); **Prop. I.1.5** requires L discretely valued and is used in Colmez's proof (Cor. I.4.6 extends scalars). With p = 2, h = 1, L = Q_2 the note's use (basis ⌊k/2⌋!C(x,k); unit ball = integral coefficients in t = (x−a)/2; v_2(β_k) ≥ v_{LA_1}(f); uniform convergence; Mahler uniqueness) matches the source exactly.
