# A363983: proof of Bala's conjecture a(m p^r) ≡ a(m p^(r−1)) (mod p^(3r)) for primes p ≥ 5

**Status.** Proved and machine-checked in Lean 4 + Mathlib (the benchmark statement verbatim, including the non-negativity that the target's `Int.toNat` requires; checks, including the benchmark's checker Comparator with the Lean and nanoda kernels, in `verification/lean-checks/A363983/README.md`). Proved by adapting the method of Osburn–Sahu–Straub (OSS), "Supercongruences for sporadic sequences", Proc. Edinburgh Math. Soc. 59 (2016), arXiv:1312.2195, proof of their Theorem 1.2 (case A = 2). A363983 is not an instance of their Theorem 1.2 (its summand has C(n,k)^1, not C(n,k)^A with A ≥ 2, a factor C(n+k−1,k) instead of C(n+k,k)^B, and the sign (−1)^{n+k}), nor of their Section 3 examples; the point is that C(n+k−1,k) = (n/k)C(n+k−1,k−1) supplies the second power of p that OSS get from C(n,k)². Conjecture: Peter Bala (OEIS A363983, 2023). Verification: every lemma below is proved, and every step was checked numerically (`numerics/scripts/a363983_oss_steps.py`, output in `numerics/out/`); further `rereview_oss_a363983.py`, `rereview_oss_a363983_wider.py`, `rereview_oss_lemmas.py` and `sweep_2026-10-15.py`; review reports `verification/referee-reports/A363983-proof--nemotron-3-ultra-free.txt`, `verification/referee-reports/A363983-proof--nemotron-3-ultra-free--rerun.txt` and `verification/referee-reports/REREVIEW-A363983-and-A376462-first--fact-only-agent.txt`.

## 0. Statement

a(n) = Σ_{k=⌊(n+1)/2⌋}^{n} (−1)^{n+k} C(n,k) C(n+k−1,k) C(2k,n)  (A363983: 1, 2, 14, 128, 1310, 14252, …). Since C(2k,n) = 0 for 2k < n and C(0,n) = 0 for n ≥ 1, for n ≥ 1 we may write a(n) = Σ_{k=1}^{n} A(n,k) with

    A(n,k) := (−1)^{n+k} C(n,k) C(n+k−1,k) C(2k,n).

**Theorem.** For every prime p ≥ 5 and all integers m, r ≥ 1: a(m p^r) ≡ a(m p^{r−1}) (mod p^{3r}).

Numerics: valuations exactly 3r in many cases (p ∈ {5,7,11,13}, m ≤ 3, r ≤ 2; `numerics/out/sweep_2026-10-15.txt`).

Throughout, Σ' denotes a sum over indices not divisible by p, N := m p^r, M := N/p = m p^{r−1}, and [x] is the floor. We assume p ∤ m throughout: if m = p^e m′ with p ∤ m′, the claim for (m, r) is the claim for (m′, r + e) weakened from modulus p^{3(r+e)} to p^{3r}; all valuation equalities such as v_p(M) = r − 1 use this. (Runs with p | m: `numerics/scripts/rereview_oss_a363983.py` and `rereview_oss_a363983_wider.py`, m ∈ {p, 2p}, all pass; the original scripts used only p ∤ m.)

## 1. Tools

**Lemma 1 (Kazandzidis, quotient form; Robert–Zuber 1995).** For p ≥ 5 and integers A > B > 0: C(pA,pB)/C(A,B) ∈ 1 + p³AB(A−B)ℤ_p (for A = B the quotient is 1 trivially). Consequently (OSS Lemma 2.1), for a, b ≥ 1 and r, s ≥ 1: C(p^r a, p^s b)/C(p^{r−1}a, p^{s−1}b) ≡ 1 (mod p^{r+s+min(r,s)}) whenever the binomials are nonzero (take A = p^{r−1}a, B = p^{s−1}b: 3 + v_p(A) + v_p(B) + v_p(A−B) ≥ r + s + min(r,s)); if p^{s−1}b > p^{r−1}a both sides vanish.

**Lemma 2 (OSS Lemma 2.2 with n = −2).** For p ≥ 5 and s ≥ 1: Σ'_{0<k<p^s} k^{−2} ≡ 0 (mod p^s), and the same holds for the half sums Σ'_{0<k<p^s/2} k^{−2} and Σ'_{p^s/2<k<p^s} k^{−2}.
Proof. Choose a unit λ with λ² ≢ 1 (mod p) (possible as p ≥ 5: x² ≡ 1 has only the roots ±1 mod p). Since k ↦ λk permutes the units mod p^s, λ^{−2} Σ' k^{−2} ≡ Σ' (λk)^{−2} ≡ Σ' k^{−2}, so (λ^{−2} − 1)Σ' k^{−2} ≡ 0 and λ^{−2} − 1 is a unit. For the halves, k ↦ p^s − k maps one half onto the other and k^{−2} ≡ (p^s − k)^{−2} (mod p^s), so both halves are congruent to half of the full sum. ∎

**Lemma 3 (OSS Lemma 2.4).** For any integer m, k ≥ 0, r ≥ 1: (−1)^k C(mp^r − 1, k) ≡ (−1)^{[k/p]} C(mp^{r−1} − 1, [k/p]) (mod p^r) (generalized binomial coefficients if m ≤ 0).
Proof. C(mp^r − 1, k) = Π_{j=1}^{k} (mp^r − j)/j. The factors with p | j, j = pλ (1 ≤ λ ≤ [k/p]), give Π_λ (mp^{r−1} − λ)/λ = C(mp^{r−1} − 1, [k/p]) exactly; the k − [k/p] factors with p ∤ j are each ≡ −1 (mod p^r) (as (mp^r − j)/j = −1 + mp^r/j with j a unit). ∎

**Lemma 4 (OSS (27), (28)).** For m, r ≥ 1, k, j ≥ 0: (i) C(mp^r + k, k) ≡ C(mp^{r−1} + [k/p], [k/p]) (mod p^r); (ii) C(j, mp^r) ≡ C([j/p], mp^{r−1}) (mod p^r).
Proof. (i) C(n+k,k) = (−1)^k C(−n−1, k); apply Lemma 3 with m replaced by −m. (ii) If j ≥ mp^r put k = j − mp^r in (i): C(j, k) = C(j, mp^r) and [k/p] = [j/p] − mp^{r−1}, so the right side is C([j/p], [j/p] − mp^{r−1}) = C([j/p], mp^{r−1}); if j < mp^r both sides are 0. ∎

## 2. Scaled terms

**Lemma 5.** For p ≥ 5, r, s ≥ 1 and p ∤ k: A(mp^r, kp^s) ≡ A(mp^{r−1}, kp^{s−1}) (mod p^{3r}).
Proof. Signs agree: (−1)^{mp^r + kp^s} = (−1)^{mp^{r−1} + kp^{s−1}} (p odd). Put K = kp^s, K' = kp^{s−1}. The three quotients are
 Q_1 = C(N, K)/C(M, K') ≡ 1 (mod p^{r+s+min(r,s)}) by Lemma 1;
 Q_2 = C(N+K−1, K)/C(M+K'−1, K') = C(N+K, K)/C(M+K', K') (because C(X−1, Y) = ((X−Y)/X) C(X,Y) and (N/(N+K))/(M/(M+K')) = 1) = C(p(M+K'), pK')/C(M+K', K') ≡ 1 (mod p^{3+v_p(M+K')+v_p(K')+v_p(M)}) by Lemma 1, and 3 + min(r−1,s−1) + (s−1) + (r−1) = r + s + min(r,s);
 Q_3 = C(2K, N)/C(2K', M) ≡ 1 (mod p^{r+s+min(r,s)}) by Lemma 1 (a = 2k, b = m, roles of r and s exchanged);
all binomials being nonzero exactly when the corresponding ones at the other level are (2K ≥ N ⇔ 2K' ≥ M, K ≤ N ⇔ K' ≤ M).
If s ≥ r, each Q_i ≡ 1 (mod p^{3r}) and the claim follows since A(M, K') ∈ ℤ. If s ≤ r, Q_1Q_2Q_3 ≡ 1 (mod p^{r+2s}), while A(M, K') is divisible by p^{2(r−s)}: v_p(C(M,K')) ≥ v_p(M) − v_p(K') ≥ r − s (as C(M,K') = (M/K')C(M−1,K'−1)) and likewise v_p(C(M+K'−1,K')) = v_p((M/K')C(M+K'−1,K'−1)) ≥ r − s. Hence A(N,K) − A(M,K') = A(M,K')(Q_1Q_2Q_3 − 1) ≡ 0 (mod p^{2(r−s)+r+2s}) = (mod p^{3r}). ∎

Consequently, writing a(N) = Σ_{s≥0} G_s(N) with G_s(N) := Σ'_k A(N, kp^s), we get G_s(N) ≡ G_{s−1}(M) (mod p^{3r}) for s ≥ 1, and since Σ_{s≥1} G_{s−1}(M) = a(M),

    a(N) − a(M) ≡ G_0(N) = Σ'_{k} A(N,k)   (mod p^{3r}).                                           (1)

## 3. The unscaled sum

For p ∤ k use C(N,k) = (N/k) C(N−1,k−1) and C(N+k−1,k) = (N/k) C(N+k−1,k−1):

    G_0(N) = (−1)^N N² · S,   S := Σ'_k (−1)^k k^{−2} C(N−1,k−1) C(N+k−1,k−1) C(2k,N).                  (2)

It remains to show S ≡ 0 (mod p^r) (then (1), (2) give the Theorem since v_p(N²) = 2r).

Define, for integers n ≥ 1 and k, j ≥ 0, the lower-level kernel D(n,k,j) := (−1)^k C(n−1,k) C(n+k,k) C(j,n). For p ∤ k we have [(k−1)/p] = [k/p], so Lemma 3 (with k−1), Lemma 4(i) (with k−1) and Lemma 4(ii) (with j = 2k) give, modulo p^r,
 (−1)^k C(N−1,k−1) = −(−1)^{k−1}C(N−1,k−1) ≡ −(−1)^{[k/p]} C(M−1,[k/p]),  C(N+k−1,k−1) ≡ C(M+[k/p],[k/p]),  C(2k,N) ≡ C([2k/p], M),
hence

    S ≡ −Σ_1,   Σ_s := Σ'_{1≤k≤N} k^{−2} D(mp^{r−s}, [k/p^s], [2k/p^s])   (s = 1, …, r)   (mod p^r)           (3)

(the terms with k ≥ N vanish anyway, since C(mp^{r−s}−1, [k/p^s]) = 0 once [k/p^s] ≥ mp^{r−s}).

**Lemma 6 (OSS (35)–(36)).** Σ_s ≡ Σ_{s+1} (mod p^r) for 1 ≤ s ≤ r−1, and Σ_r ≡ 0 (mod p^r).
Proof. Let {k}_s := k − p^s[k/p^s]. Then [2k/p^s] = 2[k/p^s] + ε with ε = 1 if {k}_s > p^s/2 and ε = 0 otherwise ({k}_s ≠ p^s/2 as p^s is odd). Grouping the k with [k/p^s] = n,
    Σ_s = Σ_n D(mp^{r−s}, n, 2n) · Σ'_{[k/p^s]=n, {k}_s<p^s/2} k^{−2} + Σ_n D(mp^{r−s}, n, 2n+1) · Σ'_{[k/p^s]=n, {k}_s>p^s/2} k^{−2}.
Each inner sum is ≡ 0 (mod p^s): for k = np^s + u, k^{−2} ≡ u^{−2} (mod p^s), and the half sums of Lemma 2 vanish mod p^s. (There is no incomplete block: N = mp^r is a multiple of p^s, so every block [np^s, (n+1)p^s) with n < N/p^s lies inside [0, N].) For s = r this already gives Σ_r ≡ 0 (mod p^r). For s < r, Lemma 3 and Lemma 4 (at level t = r − s ≥ 1, modulus p^{r−s}) give D(mp^{r−s}, n, j) ≡ D(mp^{r−s−1}, [n/p], [j/p]) (mod p^{r−s}) for all n, j ≥ 0 (the sign: (−1)^n C(mp^{r−s} − 1, n) ≡ (−1)^{[n/p]} C(mp^{r−s−1} − 1, [n/p]) is Lemma 3). Replacing each D by its lower-level value changes Σ_s by a multiple of p^{r−s}·p^s = p^r, and since [[k/p^s]/p] = [k/p^{s+1}] and [[2k/p^s]/p] = [2k/p^{s+1}], the result is exactly Σ_{s+1}. (Explicitly: after the replacement the sum reads Σ'_{1≤k≤N} k^{−2} D(mp^{r−s−1}, [[k/p^s]/p], [[2k/p^s]/p]); the grouping by n and by half-blocks served only to bound the error term Σ_n (D − D_lower)·(inner sum), each summand of which is p^{r−s}·(p-adic integer) times p^s·(p-adic integer); the nested floors collapse, and the k-sum with weights k^{−2} is by definition Σ_{s+1}.) ∎

By (3) and Lemma 6, S ≡ −Σ_1 ≡ −Σ_r ≡ 0 (mod p^r). With (1), (2): a(N) − a(M) ≡ (−1)^N N² S ≡ 0 (mod p^{3r}). ∎

## 5. Remarks
- For p = 3 the proof fails at Lemma 1 (p ≥ 5) and Lemma 2 (needs a unit λ with λ² ≢ 1 mod p); Bala's conjecture is stated for p ≥ 5.
- The same argument proves the cubic tower for the signed family Σ_k (−1)^{n+k} C(n,k)^A C(n+k−1,k)^B C(2k,n)^C when A ≥ 1 and B ≥ 1 (A + B = 2 is this note; A + B ≥ 3 is immediate from N^{A+B}), and when A ≥ 3, B = 0. The signed case A = 2, B = 0 is *not* covered and in fact fails: for Σ_k (−1)^{n+k}C(n,k)²C(2k,n) one has v_5(f(5) − f(1)) = 2 < 3 (direct computation); OSS's Theorem 1.2 (A ≥ 2) is for the unsigned family, where the block sums are Σ' u^{−2} rather than Σ'(−1)^u u^{−2}.
