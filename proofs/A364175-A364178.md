## 0. The sequences in integer form

Integer forms (A364175: Bala's formula on the OEIS, Jun 2026; A364178: derived here the same way; both verified exactly against the Γ definitions for small n; n ≥ 1, empty products at n = 0):

    A364175: a(n) = 3^n (6n)! / ( (3n)! (2n)! Π_{j=1}^{n} (2n + 3j) ),      A364178: b(n) = 2^n (10n)! (3n)! / ( (6n)! (5n)! n! Π_{j=1}^{n} (n + 2j) ).

(They come from Γ(1+2n/3)/Γ(1+5n/3) = 3^n/Π_{j≤n}(2n+3j) and Γ(1+n/2)/Γ(1+3n/2) = 2^n/Π_{j≤n}(n+2j).)

## 1. Integrality

**Theorem 1 (Radcliffe 2026, re-verified).** A364175(n) ∈ ℤ for all n.
**Theorem 2.** A364178(n) ∈ ℤ for all n. (An earlier, unreviewed proof was posted by rbajaj5 as the half-index case of A295470; see `literature/PRIOR-CLAIMS.md`. The proof below is checked in Lean.)

Proof of Theorem 2. Let q be a prime and v = v_q. For q = 2: v_2(X!) = X − s_2(X) (s_2 = binary digit sum) gives v_2(2^n(10n)!(3n)!/((6n)!(5n)!n!)) = 2n + s_2(n) (using s_2(10n) = s_2(5n), s_2(6n) = s_2(3n)). If n is odd every n + 2j is odd, so v_2(b(n)) = 2n + s_2(n) ≥ 0. If n = 2m, Π_{j≤n}(n+2j) = 2^n (3m)!/m!, whose 2-adic valuation is 2n − s_2(3m) + s_2(m), so v_2(b(n)) = s_2(3m) ≥ 0. (Both formulas checked for 1 ≤ n ≤ 39.)
For odd q: 2 is invertible mod q^k, so for each k ≥ 1 the congruence n + 2j ≡ 0 (mod q^k) has exactly one solution class, and N_k := #{1 ≤ j ≤ n : q^k | n + 2j} = ⌊n/q^k⌋ + ε_k with ε_k ∈ {0,1}. Writing n = t_k q^k + ρ_k (0 ≤ ρ_k < q^k; below t, ρ, ε stand for t_k, ρ_k, ε_k), Legendre's formula gives

    v_q(b(n)) = Σ_{k≥1} [ ⌊10n/q^k⌋ + ⌊3n/q^k⌋ − ⌊6n/q^k⌋ − ⌊5n/q^k⌋ − ⌊n/q^k⌋ − N_k ] = Σ_{k≥1} [ F(ρ/q^k) − ε_k ],

with F(x) := ⌊10x⌋ + ⌊3x⌋ − ⌊6x⌋ − ⌊5x⌋ − ⌊x⌋ (here ⌊a n/q^k⌋ = a t + ⌊a ρ/q^k⌋ for each a, so the integer part t contributes (10+3−6−5−1)t = t through the five floors and −t through N_k = t + ε_k; these cancel, and the last term −⌊x⌋ of F is 0 on [0,1) and is kept only to mirror the factorial ratio). F is piecewise constant on [0,1) with breakpoints at multiples of 1/10, 1/6, 1/5, 1/3; its values are 0 on [0,1/10) ∪ [1/6, 3/10) and ≥ 1 on [1/10,1/6) ∪ [3/10, 1) (table: F = 1 on [1/10,1/6), [3/10,7/10), [5/6,9/10); F = 2 on [7/10,5/6), [9/10,1)). Now ε_k = 1 means some s ∈ [1, ρ] has q^k | ρ + 2s; as 0 < ρ + 2s ≤ 3ρ < 3q^k, this forces ρ + 2s ∈ {q^k, 2q^k} and in either case q^k ≤ 3ρ, i.e. ρ/q^k ≥ 1/3, where F ≥ 1. Hence every summand F(ρ/q^k) − ε_k is ≥ 0 and v_q(b(n)) ≥ 0. ∎
(Radcliffe's proof of Theorem 1 has the same shape with F(x) = ⌊6x⌋−⌊3x⌋−⌊2x⌋ ∈ {0,1,2}, zero only on [0,1/6), ε = 1 forcing ρ/q^k ≥ 1/5, for q ≠ 3; q = 3 handled separately via the Vasyunin ratio (18m)!(2m)!/((9m)!(6m)!(5m)!) when 3 | n and the factor 3^n when 3 ∤ n.)
Computer checks: b(n) ∈ ℤ for n ≤ 1500 by valuations at the primes q ≤ 10n (odd q throughout, and also q = 2 for n ≤ 400; 1.4·10^6 pairs in all; v_2 is otherwise given by the proven formula) and as exact rationals for n ≤ 120; for a(n) the valuation sweep covers the odd primes q ≠ 3 for n ≤ 1500 (q = 3 is handled by the proven digit formula, and a(n) is an exact integer for n ≤ 120) (`numerics/out/unit_product_principle.txt`).

## 2. The unit-product principle (p ≥ 5)

Notation: for X ≥ 0, U(X) := Π_{1≤k≤X, p∤k} k; W_r := U(p^r); R_r := {u : 0<u<p^r, p∤u}; S_j := Σ_{u∈R_r} u^{−j}. Recall (Lemma 2 of `proofs/TheoremF-p-ge-5.md`): S_1 ≡ 0 (mod p^{2r}) and S_2 ≡ 0 (mod p^r) for p ≥ 5.

**Lemma A (unit products).** Let N = n p^r (n ≥ 1, r ≥ 1), a ≥ 1. Then U(aN) ≡ W_r^{an} (mod p^{3r}).
Proof. The units in (0, aN] are bp^r + u with 0 ≤ b < an, u ∈ R_r. So U(aN) = Π_b Π_u (bp^r + u) = W_r^{an} Π_{b} P_b, P_b := Π_u (1 + bp^r/u). Expanding, P_b − 1 = bp^r e_1 + b²p^{2r} e_2 + b³p^{3r}e_3 + … with e_j the elementary symmetric functions of the u^{−1}, u ∈ R_r (all in ℤ_(p)): e_1 = S_1 has v_p ≥ 2r, e_2 = (S_1² − S_2)/2 has v_p ≥ r, so every term is ≡ 0 (mod p^{3r}). Hence P_b ≡ 1 (mod p^{3r}). (Equivalently via log P_b = Σ_j (−1)^{j+1}b^jp^{jr}S_j/j, using v_p(log(1+x)) = v_p(x) for x ∈ pℤ_p.) ∎
**Lemma B (linear-form products).** Let N = np^r, and c, d integers with p ∤ d. Then Π_{1≤k≤N, p∤k} (1 + cN/(dk)) ≡ 1 (mod p^{3r}).
Proof. All factors are 1-units, so it suffices that the p-adic logarithm of the product, Σ_{j≥1} (−1)^{j+1}(cN/d)^j H^{(j)}/j with H^{(j)} := Σ_{p∤k≤N} k^{−j} = Σ_{b<n} Σ_{u∈R_r} (bp^r+u)^{−j} ∈ ℤ_(p), is ≡ 0 (mod p^{3r}) (v_p(log(1+x)) = v_p(x) for x ∈ pℤ_p, p odd). Since (bp^r+u)^{−1} ≡ u^{−1} − bp^r u^{−2} (mod p^{2r}) and (bp^r+u)^{−2} ≡ u^{−2} (mod p^r): H^{(1)} ≡ Σ_b (S_1 − bp^r S_2) ≡ 0 (mod p^{2r}) and H^{(2)} ≡ n S_2 ≡ 0 (mod p^r). So the j = 1 term has valuation ≥ r + 2r, the j = 2 term ≥ 2r + r, and the j ≥ 3 terms ≥ jr − v_p(j) ≥ 3r (p ≥ 5). ∎
**Lemma C (Legendre).** For every X ≥ 0, X! = p^{⌊X/p⌋} ⌊X/p⌋! · U(X).  (Split the factors of X! into multiples of p and units.)

Remark. With Lemma C, Lemma A gives at once: for any integer factorial ratio F(N) = Π_i (a_i N)!^{ε_i} with Σ ε_i a_i = 0 ("balanced"), F(pM)/F(M) = Π_i U(a_i pM)^{ε_i} ≡ W_r^{(Σ ε_i a_i) n} = 1 (mod p^{3r}) where pM = np^r — the cubic tower for all balanced factorial ratios (in particular Jacobsthal–Kazandzidis and the Bober–Vasyunin ratios), for p ≥ 5, provided F(M) is p-integral.

## 3. The towers

Let p ≥ 5, N = np^r, M = N/p = np^{r−1}.

**Theorem 3.** a(N)/a(M) ≡ 1 and b(N)/b(M) ≡ 1 (mod p^{3r}). Consequently (Theorems 1, 2 give the p-integrality of a(M), b(M) that is needed) A364175(np^r) ≡ A364175(np^{r−1}) and A364178(np^r) ≡ A364178(np^{r−1}) (mod p^{3r}).

Proof. Exact identities (checked by computer for p ∈ {5,7,11}, r ≤ 2, n ≤ 3 — 17 cases in `numerics/out/unit_product_principle.txt`; independently also checked at (11,2,3), p = 13 and p = 5, r = 3):

    a(N)/a(M) = U(6N) / ( U(3N) U(2N) U(N) ) · Π_{p∤k≤N} (1 + 2N/(3k))^{−1},
    b(N)/b(M) = U(10N) U(3N) / ( U(6N) U(5N) U(N)² ) · Π_{p∤k≤N} (1 + N/(2k))^{−1}.

Derivation for b: by Lemma C, (10N)!(3N)!/((6N)!(5N)!N!) = p^{(10+3−6−5−1)M}·[(10M)!(3M)!/((6M)!(5M)!M!)]·U(10N)U(3N)/(U(6N)U(5N)U(N)). In Π_{j≤N}(N+2j), the factors with p | j (j = pj') are p(M + 2j') and reproduce p^M Π_{j'≤M}(M+2j'); the factors with p ∤ j are 2j(1 + N/(2j)), whose product is 2^{N−M} U(N) Π_{p∤j≤N}(1 + N/(2j)). The powers of p and of 2 cancel (2^N/2^M against 2^{N−M}), giving the identity. The derivation for a is identical with Π_{j≤N}(2N+3j): the p ∤ j factors are 3j(1 + 2N/(3j)), the p | j factors p(2M+3j'), and 3^{N−M} cancels against 3^N/3^M.
By Lemma A each U(aN) ≡ W_r^{an}, so U(6N)/(U(3N)U(2N)U(N)) ≡ W_r^{(6−3−2−1)n} = 1 and U(10N)U(3N)/(U(6N)U(5N)U(N)²) ≡ W_r^{(10+3−6−5−2)n} = 1 (mod p^{3r}); by Lemma B the linear-form products are ≡ 1. Hence the ratios are ≡ 1 (mod p^{3r}); multiplying by the integer a(M) (resp. b(M)) gives the congruences. ∎

Numerics (`numerics/out/sweep_2026-10-15.txt`, `unit_product_principle.txt`): v_p(a(np^r) − a(np^{r−1})) − 3r ≥ 0 for p ∈ {5,7,11,13} (ratio-form slack 0 or 1; the difference can have larger slack when v_p(a(n)) > 0); Lemmas A and B attained (slack 0).

## 4. Remarks
- Theorem 3 holds for the ratios unconditionally (no integrality needed), and shows v_p(a(np^r)) = v_p(a(n)) for all r when p ≥ 5.
- p = 3 (resp. p = 2) are excluded by Lemma A (needs 6 invertible) and for A364175 also by the linear forms 2N + 3j (3 | d). Bala's conjectures are stated for p ≥ 5.
- The same two lemmas prove the "quotient tower" (ratio ≡ 1 mod p^{3r}) for every ratio of the form v^N Π(a_iN)!^{ε_i} / Π_{j≤N}(uN + vj) with Σ ε_i a_i = 1 and p ∤ v; several of Bala's other "fractional factorial" sequences (A364172–A364184) appear to have this shape, but we checked only A364175 and A364178; integrality must be checked case by case as in §1. The data suggest the b-tower also holds at p = 3 (unproved).
