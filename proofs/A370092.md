# A370092: proof of Bala's eventual-periodicity conjecture (period divides φ(k) for every k > 2)

**Status.** Machine-checked in Lean 4 + Mathlib (the benchmark statement; `verification/lean-checks/A370092/README.md`). The Lean proof replaces Lemma B's use of Amice's theorem by an elementary argument, described in that README; the sharpness of φ(k) is not part of the Lean statement. Proved. For odd prime powers the proof is a two-line extension of Kallat's argument (arXiv:2609.07238, Prop. 2.1) to generating functions with 2-power denominators; for powers of two it is new and rests on a 2-adic lemma about Stirling numbers (Lemma B) proved with Amice's theorem on Mahler coefficients plus finite checks. The φ(k) bound is sharp for k = 2^α (α ≥ 3): the Carmichael function λ(2^α) = 2^{α−2} is *not* a period, so A370092 lies outside the class G ∈ ℤ[[y]] treated by Kallat and behaves differently from the Fubini numbers. Conjecture: Peter Bala (OEIS A370092, Feb 2024; "see A000670 for a more general conjecture"). Verification: the scripts listed in §6 (`numerics/scripts/a370092_periodicity.py`, `lemmaB_k15_residue_check.py`, `rereview_a370092_*.py`, `a370092_powers_of_two.py`, `a370092_termwise_2adic.py`, `lemmaB_stirling_2adic.py`, `lemmaB_amice_parts.py`, `lemmaB_finite_checks.py`; outputs in `numerics/out/`); review reports `verification/referee-reports/A370092-periodicity-proof--nemotron-3-ultra-free.txt` and `verification/referee-reports/REREVIEW-A370092--fact-only-agent.txt`.

## 0. The sequence

a(0)=1, a(n) = (−1)^n + ½ Σ_{j=1}^{n} (1 − (−1)^j − (−2)^j) C(n,j) a(n−j); e.g.f. F(x) = 2e^x/(1 + e^x + e^{2x} − e^{3x}). Values 1, 1, 3, 16, 105, 856, 8433, …

With u = e^x − 1: 1 + e^x + e^{2x} − e^{3x} = 2 − 2u² − u³, so F = G(e^x − 1) with

    G(u) = (1 + u)/(1 − u² − u³/2) = Σ_k g_k u^k,   g_0 = g_1 = g_2 = 1, g_3 = 3/2, …,   2g_k = 2g_{k−2} + g_{k−3} (k ≥ 3).

**Theorem.** Let k ≥ 3. The sequence a(n) mod k is eventually periodic with a period dividing φ(k); explicitly a(n + φ(k)) ≡ a(n) (mod k) for all n ≥ max_{p^α ∥ k} α + 1. (For k = 2 the period is 2 ≠ φ(2), as Bala's hypothesis k > 2 anticipates.)

## 1. Stirling expansion and integrality

Since (e^x − 1)^k = Σ_n k! S(n,k) x^n/n!,  a(n) = Σ_{k=0}^{n} c_k S(n,k) with c_k := k! g_k.          (1)

(P1) v_2(g_k) ≥ −⌊k/3⌋, and g_k ∈ ℤ[1/2]. Proof: G = (1+u) Σ_m (u² + u³/2)^m; the coefficient of u^j in (u²+u³/2)^m is C(m,r)/2^r with 2m + r = j, 0 ≤ r ≤ m, hence r = j − 2m ≤ j − 2⌈j/3⌉ ≤ ⌊j/3⌋; the factor (1+u) only adds the coefficient of u^{k−1}.
(P2) c_k ∈ ℤ: v_2(k!) = k − s_2(k) ≥ k − ⌊log_2 k⌋ − 1 ≥ ⌊k/3⌋ for k ≥ 16, and directly for k ≤ 15; moreover v_2(k!) − ⌊k/3⌋ ≥ 2 for k ≥ 6 (k ≥ 12 by the same bound, 6 ≤ k ≤ 11 directly). Hence a(n) ∈ ℤ for all n (the OEIS/benchmark statement "conjecturally integers" is settled by (1)).
(P3) For every modulus and every P ≥ 1:   a(n + P) − a(n) = Σ_k g_k b_k(n, P),   b_k(n,P) := k!(S(n+P,k) − S(n,k)) = Σ_{j=0}^{k} (−1)^{k−j} C(k,j) j^n (j^P − 1).   (finite sums)

## 2. Odd prime powers

**Proposition 1.** Let p be an odd prime, α ≥ 1, P = φ(p^α). Then a(n + P) ≡ a(n) (mod p^α) for all n ≥ α.

Proof. For every j ≥ 0 and n ≥ α: if p | j then j^n ≡ 0, if p ∤ j then j^P ≡ 1 (mod p^α); so every term of b_k(n,P) in (P3) is ≡ 0 (mod p^α), hence b_k(n,P) ∈ p^α ℤ. Since g_k ∈ ℤ[1/2] ⊂ ℤ_(p), g_k b_k ∈ p^α ℤ_(p), and a(n+P) − a(n) ∈ p^α ℤ_(p) ∩ ℤ = p^α ℤ. ∎
(This is Kallat's proof of his Prop. 2.1 with "G ∈ ℤ[[y]]" weakened to "G has p-integral coefficients". It shows λ(p^α) = φ(p^α) is a period; numerically it is the minimal period for p^α ∈ {3,9,27,81,243,5,25,125,7,49,343}.)

## 3. Powers of two

**Lemma B.** Let m ≥ 2, P = 2^m, k ≥ 0 and n ≥ m + 2. Then v_2(b_k(n, 2^m)) ≥ m + 1 + ⌊k/3⌋.

(Numerically: holds for all 2 ≤ m ≤ 10, k ≤ 70, m+2 ≤ n ≤ 260, and fails for some k at every n ≤ m+1; over n ∈ [40, 200] and m ∈ {5, 8} the minimum of v_2(b_k) − m is 2, 4, 2, 3, 3, 6, 5, 6, 6, 8, … for k = 3, 4, 5, … (`numerics/out/lemmaB_stirling_2adic.txt`); over the lemma's full range n ≥ m+2 the minima are smaller and can depend on m (k = 4: 3, attained at n = m+2 for every m; k = 8: 5 or 6; k = 12: 6 to 8 for m = 2..9), still ≥ the required 1 + ⌊k/3⌋ in every case — `numerics/out/rereview_a370092_profile_k4.txt`, `numerics/out/rereview_a370092_lemmaB.txt`.)

**Proposition 2.** For α ≥ 3, a(n + 2^{α−1}) ≡ a(n) (mod 2^α) for all n ≥ α + 1. For α = 2: a(n+2) ≡ a(n) (mod 4) for n ≥ 3; for α = 1: a(n+2) ≡ a(n) (mod 2) for n ≥ 2.

Proof. α ≥ 3: take m = α − 1 ≥ 2 in (P3): v_2(g_k b_k) ≥ −⌊k/3⌋ + (m + 1 + ⌊k/3⌋) = α for every k by (P1) and Lemma B, so the finite sum is ≡ 0 (mod 2^α). α ≤ 2: v_2(c_k) ≥ 2 for all k ≥ 4 (c_4 = 24 g_4 with g_4 = g_2 + g_1/2 = 3/2, c_4 = 36; c_5 = 120·g_5, g_5 = g_3 + g_2/2 = 2; and for k ≥ 6, v_2(k!) − ⌊k/3⌋ ≥ 2 by (P2)), so a(n) ≡ c_1 S(n,1) + c_2 S(n,2) + c_3 S(n,3) = 1 + 2(2^{n−1} − 1) + 9 (3^{n−1} − 2^n + 1)/2 (mod 4) for n ≥ 1. For n ≥ 3 this is ≡ −1 + (9/2)(3^{n−1} + 1) ≡ 0 (n odd), 1 (n even) (mod 4), using (3^{n−1}+1)/2 ≡ 1 or 2 (mod 4) according as n is odd or even; this gives the α = 2 clause. Reducing further mod 2: for n ≥ 2, a(n) ≡ 1 + (3^{n−1}+1)/2 ≡ 0 (n odd), 1 (n even) (mod 2) (the term 2^{n−1}·9 is even for n ≥ 2), which gives the α = 1 clause with start n = 2 (indeed a(1) = 1 ≢ a(3) = 16 (mod 2), so n ≥ 2 is sharp). ∎

**Proof of Lemma B.** Put F(x) = x^n (x^{2^m} − 1), a polynomial function ℤ_2 → ℤ_2; then b_k = Σ_j (−1)^{k−j} C(k,j) F(j) = Δ^k F(0) is its k-th Mahler coefficient. Local expansions in the variable t ∈ ℤ_2:
  • on the even class, F(2t) = 2^n t^n ((2t)^{2^m} − 1) ∈ 2^n ℤ_2[t];
  • on the odd class, F(1+2t) = (1+2t)^n ((1+2t)^{2^m} − 1), and (1+2t)^{2^m} − 1 = Σ_{i≥1} C(2^m, i) 2^i t^i with v_2(C(2^m,i) 2^i) = m − v_2(i) + i ≥ m + 1 (equality exactly for i = 1, 2; ≥ m + 2 for i ≥ 3). Hence F(1+2t) ∈ 2^{m+1} ℤ_2[t].
Since n ≥ m + 2, the function f := 2^{−(m+1)} F is analytic on each class mod 2 with ℤ_2-integral coefficients in the normalised variable t = (x − a)/2, i.e. f lies in the unit ball of LA_1(ℤ_2, ℚ_2) in the sense of Colmez, Fonctions d'une variable p-adique (Astérisque 330, 2010), §I.4, rem. I.4.4/lemma I.4.5. By Amice's theorem (loc. cit., Théorème I.4.7: the functions ⌊k/p^h⌋!·C(x,k) form an orthonormal basis of LA_h(ℤ_p, L); L = ℚ_2 is discretely valued, as required in Colmez's proof via Prop. I.1.5), f = Σ_k β_k ⌊k/2⌋! C(x,k) with v_2(β_k) ≥ v_{LA_1}(f) ≥ 0 and the series converging in LA_1, hence uniformly (Prop. I.4.3); by uniqueness of Mahler expansions of continuous functions, a_k(f) = β_k ⌊k/2⌋!, so v_2(a_k(f)) ≥ v_2(⌊k/2⌋!). Therefore

    v_2(b_k) ≥ m + 1 + v_2(⌊k/2⌋!)   for all k ≥ 0, n ≥ m+1.                                   (2)

(Sanity check: 200 random functions with polynomial local expansions, k < 45: minimum of v_2(a_k) − v_2(⌊k/2⌋!) equals 0; and (2) itself has minimum slack 0 in the data.)
Now v_2(⌊k/2⌋!) ≥ ⌊k/3⌋ for every k ∉ {3, 6, 7, 15} (checked for k ≤ 400 by computer; for k > 400, v_2(⌊k/2⌋!) ≥ ⌊k/2⌋ − log_2(k) − 1 > k/3). This proves Lemma B for k ∉ {3, 6, 7, 15}.
For k ∈ {3, 6, 7, 15} refine the odd class: write (1+2t)^{2^m} − 1 = 2^{m+1}[t + (2^m − 1) t²] + 2^{m+2} R_m(t) with R_m(t) = Σ_{i≥3} C(2^m,i) 2^{i−m−2} t^i ∈ ℤ_2[t] (v_2 of the coefficients is i − 2 − v_2(i) ≥ 0). Then b_k = E_k + 2^{m+1} S_1 + 2^{m+2} S_2 with
  E_k = Σ_{j even} (−1)^{k−j} C(k,j) F(j)  (Mahler coefficient of F·1_{2ℤ_2}; this function is analytic on each class mod 2 — it equals F(2t) on the even class and 0 on the odd class — hence lies in LA_1 and is in particular continuous, since the classes mod 2 are open; its local coefficients lie in 2^n ℤ_2, so Amice's theorem applies as above): v_2(E_k) ≥ n + v_2(⌊k/2⌋!) ≥ m + 2 + v_2(⌊k/2⌋!);
  S_2 = Σ_t (−1)^{k−1−2t} C(k,2t+1) (1+2t)^n R_m(t)  (Mahler coefficient of the function that is 0 on the even class and (1+2t)^n R_m(t) at x = 1+2t on the odd class; again in LA_1 with ℤ_2-integral local coefficients): v_2(S_2) ≥ v_2(⌊k/2⌋!);
  S_1 = Σ_{t=0}^{⌊(k−1)/2⌋} (−1)^{k−1−2t} C(k,2t+1) (1+2t)^n t (1 + (2^m − 1) t)  (an explicit finite integer sum).
For these four k one has v_2(⌊k/2⌋!) + 1 = ⌊k/3⌋ (values 1, 2, 2, 5), so E_k and 2^{m+2}S_2 are ≡ 0 (mod 2^{m+1+⌊k/3⌋}) and it remains to show v_2(S_1) ≥ ⌊k/3⌋ =: d ∈ {1, 2, 2, 5}. Modulo 2^d, S_1 depends on n only through (1+2t)^n mod 2^d (period dividing λ(2^d) = 1, 2, 2, 8 for d = 1, 2, 2, 5) and on m only through (2^m − 1) mod 2^d; so finitely many cases remain: m = 2, …, d together with one m ≥ d, and for each m a full period of n ≥ m + 2. All are verified by the self-contained script `numerics/scripts/lemmaB_k15_residue_check.py` (output `numerics/out/lemmaB_k15_residue_check.txt`: m = 2..9, n = m+2..m+33, 256 cases per k, 0 violations; the minimum of v_2(S_1) is 2, 2, 2, 9 for k = 3, 6, 7, 15), and independently by `numerics/scripts/lemmaB_finite_checks.py` (direct check of v_2(b_k) for m = 2..10 and 70 values of n each). By hand: k = 3: S_1 = 3^n·1·(1 + (2^m−1)) = 2^m·3^n, v_2 ≥ 1 (in fact b_3 = 3^n(3^{2^m} − 1) − 3·2^n(2^{2^m}−1) has v_2 = m + 2 exactly for n ≥ m + 3, and ≥ m + 2 for n = m + 2). k = 6: S_1 = −20·3^n·(2^m) − 6·5^n·2·(1 + 2(2^m−1)) ≡ 0 (mod 4). k = 7: S_1 = 35·3^n 2^m + 21·5^n·2(2^{m+1} − 1) + 7^n·3(3·2^m − 2) ≡ 2·21·5^n·(−1) + 7^n·(−6) ≡ −2(21·5^n + 3·7^n) ≡ 0 (mod 4) since 21·5^n + 3·7^n is even. ∎

## 4. Assembling the theorem

Let k ≥ 3 and write k = 2^α Π p_i^{α_i}. If a(n + P_1) ≡ a(n) mod q_1 and a(n + P_2) ≡ a(n) mod q_2 for n ≥ n_0 then a(n + lcm(P_1,P_2)) ≡ a(n) mod lcm(q_1, q_2) for n ≥ n_0. By Propositions 1–2, a(n) mod k has the period L := lcm(2^{α−1} [if α ≥ 2], 2 [if α = 1], φ(p_i^{α_i})) from n ≥ max(α_i + 1, α + 1) (Prop. 1 gives start α_i, Prop. 2 gives start α + 1 for all α ≥ 1). If α ≥ 2, L | 2^{α−1} Π φ(p_i^{α_i}) = φ(k). If α = 1 then k > 2 forces some odd p_i, so φ(k) = Π φ(p_i^{α_i}) is even and L | φ(k). If α = 0, L | φ(k) trivially. ∎

## 5. Sharpness and remarks
- Minimal periods measured (`numerics/out/a370092_powers_of_two.txt`, N = 1200 terms): mod 2^α (α = 2..9) the minimal period is exactly 2^{α−1} = φ(2^α) (true preperiod α+1 for α ∈ {2,…,6, 8, 9, 10, 12} and α for α ∈ {7, 11}, `numerics/out/rereview_a370092_pow2_deep.txt`), while λ(2^α) = 2^{α−2} for α ≥ 3; mod 3^α, 5^α, 7^α the minimal period is exactly φ(p^α) = λ(p^α). So Bala's φ(k) is optimal and cannot be replaced by λ(k) as in Kallat's theorem for integral G; the loss of one factor 2 is caused by the denominators 2^{⌊k/3⌋} of g_k, which are compensated termwise by Lemma B — the data show that termwise compensation is tight (slack 0 at k = 3).
- The same proof works verbatim for any e.g.f. G(e^x − 1) with G ∈ ℤ[1/2][[u]] and v_2(g_k) ≥ −⌊k/3⌋ (e.g. G = (polynomial)/(1 − u² − u³/2)); with weaker denominator control (v_2(g_k) ≥ −⌊k/2⌋ or so) Lemma B's margin is exhausted and a different argument would be needed. Bala's "more general conjecture" on A000670 is for integral G, which is Kallat's theorem.
- Not proved here: Gauss-type congruences a(np^r) ≡ a(np^{r−1}) (mod p^r) for A370092 (not conjectured on the entry).
