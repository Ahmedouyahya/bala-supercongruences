# Sweep of Bala's fractional-factorial family A364172–A364184 with the unit-product machinery (2026-10-15)

**Status.** Proved for A364172 and A364179 (integrality, hence, with Theorem U below, Bala's cubic towers; for A364179 an earlier, unreviewed proof was posted by rbajaj5 as the half-index case of A295471, 2026-08-13, see `literature/PRIOR-CLAIMS.md`); for the other nine entries of the family the tower is proved here modulo p-integrality, which remains numerical here (rbajaj5's drafts claim integrality proofs for several of them, for example A364173, A364176 and A364183). Method: the unit-product machinery (Lemmas A and B) of `proofs/A364175-A364178.md`, applied to the thirteen sibling entries A364172–A364184 that carry the same conjecture ("a(np^r) ≡ a(np^{r−1}) (mod p^{3r}) for p ≥ 5") and, except A364175, the status "only conjecturally an integer sequence"; integrality by Legendre's formula with digit sums at the exceptional prime. Conjecture: Peter Bala (OEIS A364172–A364184). Verification: `numerics/scripts/fractional_factorial_sweep.py` (output `numerics/out/fractional_factorial_sweep.txt`), `a364172_a364179_integrality.py` and `a364172_q2_digits.py` (outputs in `numerics/out/`); no review report concerns this note specifically, its lemmas being those of `proofs/A364175-A364178.md` (see the reports listed there).

## Integer forms
Each entry is Π_i (a_i n)!^{ε_i} · Π_t (x_t n/d_t)!/(y_t n/d_t)! with y_t − x_t = c_t d_t, and (x n/d)!/(y n/d)! = d^{cn}/Π_{j=1}^{cn}(xn + dj) (or the reciprocal product when y < x, as in A364174's (3n/2)!/(n/2)! = Π_{j≤n}(n/2 + j)). All thirteen integer forms reproduce the OEIS data lines.

## Theorem U (ratio towers; proved by Lemma A + Lemma B of the A364 note)

*Priority.* The same reduction of all thirteen towers to integrality was claimed earlier in rbajaj5's unreviewed draft `RationalGammaRatioCubicTowers.md` (§5, first committed 2026-08-01), by the same unit-product/gamma-ratio transfer; the proof below is our own write-up of it (`literature/PRIOR-CLAIMS.md`).
Let R(n) = Π_i (a_i n)!^{ε_i} · Π_t (x_t n/d_t)!/(y_t n/d_t)! be balanced in the Γ-degree sense (Σ_i ε_i a_i = Σ_t c_t, counting c_t negatively for inverted pairs), with all d_t ≥ 1 and y_t ≥ 0. Then for every prime p ≥ 5 with p ∤ Π d_t, and all n, r ≥ 1: R(np^r)/R(np^{r−1}) ≡ 1 (mod p^{3r}).
Proof sketch (identical to §3 of the A364 note): by Legendre's splitting, the integer factorials contribute p^{M·Σε_ia_i}·Π_i U(a_iN)^{ε_i}·(level-M value); each product Π_{j≤cN}(xN + dj) splits into the p | j factors, which reproduce p^{cM}·Π_{j'≤cM}(xM + dj'), and the p ∤ j factors d j (1 + xN/(dj)), whose product is d^{cN−cM}·U(cN)·Π_{p∤j≤cN}(1 + xN/(dj)); the powers of p and of d cancel by balance, Lemma A gives Π U(·)^{±} ≡ W_r^{(Σε_ia_i − Σc_t)n} = 1, and Lemma B gives Π_{p∤j≤cN}(1 + xN/(dj)) ≡ 1 (mod p^{3r}) (with N replaced by cN, still a multiple of p^r). ∎
Numerics: ratio slack v_p(R(N)/R(M) − 1) − 3r ≥ 0, minimum 0, for all thirteen entries, p ∈ {5,7}, r ≤ 2, n ≤ 2.

Consequence: for each entry, Bala's congruence holds for every prime p ≥ 5 at which the sequence is p-integral (the difference a(N) − a(M) = a(M)(R(N)/R(M) − 1)); so the conjecture reduces to p-integrality, and v_p(a(np^r)) = v_p(a(n)) for p ≥ 5.

## Integrality status
Exact arithmetic: all thirteen are integers for n ≤ 120. The sufficient floor criterion of the A364 note (F(x) := Σ ε_i⌊a_i x⌋ − Σ_t ⌊c_t x⌋ ≥ #{t : x ≥ 1/y_t} on [0,1), which settles q-integrality at every odd prime q ∤ Π d_t) holds for **A364172, A364175, A364178, A364179** and fails on an interval for the other nine (e.g. A364174 at x ∈ [1/5, …), A364180/A364181 at x ≈ 2/3, A364182 at 1/2, A364173/A364183/A364184 at 1/3). For those nine, integrality (which the data support) would need the finer residue analysis of the indices j with q^k | x_t n + d_t j, as in Radcliffe's treatment of q = 3 for A364175; and in all cases the primes q | d_t and q = 2 need the digit-sum arguments used for A364178.

Conclusion: beyond A364175 and A364178 (fully done), **A364172 and A364179 are within reach** (floor criterion holds; remaining: q = 2 and q = 3 for A364172, q = 2 for A364179, by the digit-sum method), and the congruence part is proved for all thirteen modulo p-integrality. Not pursued further today.

## Addendum (2026-10-15, night): A364172 and A364179 are integer sequences, hence Bala's conjectures on them are proved

Integer forms (from the table above): A364172(n) = 3^n (6n)! / ((3n)!(2n)!·Π_{j=1}^{n}(n+3j)), A364179(n) = 2^n (10n)! / ((5n)!(4n)!·Π_{j=1}^{n}(n+2j)).

**Theorem.** A364172(n) ∈ ℤ and A364179(n) ∈ ℤ for all n ≥ 1. Consequently (Theorem U above, with d = 3 resp. d = 2, so every prime p ≥ 5 is admissible) A364172(np^r) ≡ A364172(np^{r−1}) and A364179(np^r) ≡ A364179(np^{r−1}) (mod p^{3r}) for all primes p ≥ 5 and n, r ≥ 1, as conjectured by Bala.

Proof. Write v = v_q and use Legendre's formula v_q(X!) = Σ_{k≥1}⌊X/q^k⌋ and, for q = 2, 3, the digit forms v_2(X!) = X − s_2(X), v_3(X!) = (X − s_3(X))/2 (s_q = base-q digit sum).

(1) A364172 at a prime q ≠ 3. Since 3 is invertible modulo q^k, the j ∈ [1,n] with q^k | n + 3j form one residue class modulo q^k, so N_k := #{1 ≤ j ≤ n : q^k | n+3j} = t_k + ε_k with n = t_kq^k + ρ_k (0 ≤ ρ_k < q^k) and ε_k := [∃ s ∈ [1,ρ_k] : q^k | ρ_k + 3s] ∈ {0,1} (the solutions in (t_kq^k, n] are the j = t_kq^k + s with q^k | n + 3j, i.e. q^k | ρ_k + 3s). Hence v_q(A364172(n)) = v_q(3^n) + Σ_k [⌊6n/q^k⌋ − ⌊3n/q^k⌋ − ⌊2n/q^k⌋ − t_k − ε_k] = v_q(3^n) + Σ_k [F(ρ_k/q^k) − ε_k] with F(x) := ⌊6x⌋ − ⌊3x⌋ − ⌊2x⌋ (the multiples of t_k cancel: 6 − 3 − 2 − 1 = 0). On [0,1): F = 0 on [0,1/6), F = 1 on [1/6,5/6), F = 2 on [5/6,1). If ε_k = 1 then 0 < ρ_k + 3s ≤ 4ρ_k < 4q^k forces ρ_k + 3s ∈ {q^k, 2q^k, 3q^k}, so q^k ≤ 4ρ_k, i.e. ρ_k/q^k ≥ 1/4 > 1/6 and F(ρ_k/q^k) ≥ 1. Every summand is ≥ 0 and v_q(A364172(n)) ≥ 0. (This includes q = 2.)
(2) A364172 at q = 3. v_3(3^n(6n)!/((3n)!(2n)!)) = n + (3n − s_3(6n) + s_3(3n) − 2n + s_3(2n))/2 = (3n + s_3(n))/2, using s_3(3X) = s_3(X) and s_3(6n) = s_3(2n). If 3 ∤ n, every n + 3j is prime to 3 and v_3(A364172(n)) = (3n + s_3(n))/2 ≥ 0. If n = 3m, Π_{j≤n}(n+3j) = 3^n(m+n)!/m! = 3^n(4m)!/m!, of valuation n + (3m − s_3(4m) + s_3(m))/2, so v_3(A364172(n)) = (3n + s_3(3m) − 2n − 3m + s_3(4m) − s_3(m))/2 = s_3(4m)/2 ≥ 0.
(3) A364179 at an odd prime q. As in (1) with d = 2: N_k = t_k + ε_k, ε_k = [∃ s ∈ [1,ρ_k] : q^k | ρ_k + 2s], and v_q(A364179(n)) = v_q(2^n) + Σ_k [F(ρ_k/q^k) − ε_k] with F(x) := ⌊10x⌋ − ⌊5x⌋ − ⌊4x⌋ (10 − 5 − 4 − 1 = 0). On [0,1): F = 0 exactly on [0,1/10) ∪ [1/4,3/10), F = 1 on [1/10,1/4) ∪ [3/10,7/10) ∪ [3/4,9/10), F = 2 on [7/10,3/4) ∪ [9/10,1). If ε_k = 1 then 0 < ρ_k + 2s ≤ 3ρ_k < 3q^k forces q^k ≤ 3ρ_k, i.e. ρ_k/q^k ≥ 1/3 > 3/10, where F ≥ 1. So v_q(A364179(n)) ≥ 0.
(4) A364179 at q = 2. v_2(2^n(10n)!/((5n)!(4n)!)) = n + 5n − 4n + s_2(4n) = 2n + s_2(n) (s_2(10n) = s_2(5n), s_2(4n) = s_2(n)). If n is odd every n + 2j is odd and v_2(A364179(n)) = 2n + s_2(n) ≥ 0. If n = 2m, Π_{j≤n}(n+2j) = 2^n(3m)!/m! has valuation 2n − s_2(3m) + s_2(m), so v_2(A364179(n)) = s_2(n) + s_2(3m) − s_2(m) = s_2(3m) ≥ 0. ∎

Checks (`numerics/scripts/a364172_a364179_integrality.py`, `numerics/scripts/a364172_q2_digits.py`, outputs in `numerics/out/`): both sequences are integers for n ≤ 200 (exact rationals); the closed forms v_3(A364172(n)) = (3n+s_3(n))/2 or s_3(4m)/2 and v_2(A364179(n)) = 2n+s_2(n) or s_2(3m) hold for n ≤ 200; v_2(A364172(n)) ≥ 0 with equality exactly at the powers of 2 up to 2000 (consistent with (1), where for n = 2^a the two summands with ε_k = 1 are exactly compensated).

Status of the family: A364172, A364175, A364178, A364179 fully proved (integrality + tower); the other nine: tower proved modulo p-integrality, integrality still only numerical (floor criterion fails on an interval; a finer residue analysis would be needed).
