# A386548: proof of Bala's conjecture a(n p^k) ≡ a(n p^(k−1)) (mod p^(2k)), p ≥ 5

**Status.** Proved and machine-verified in Lean 4 + Mathlib (`lean/BalaProofs/A386548.lean`, the benchmark statement verbatim; all checks, including the benchmark's checker Comparator with the Lean and nanoda kernels, in `verification/lean-checks/A386548/README.md`). The proof is elementary given Kazandzidis's congruence in quotient form (Robert–Zuber 1995, quoted in §5); the argument is an adaptation, with signs, of the "divisibility synchronization" proof that rbajaj5 wrote for A246437 (`MixedStepCoefficientQuadraticTower.md`, unreviewed draft, Aug 2026, in the repository named in `literature/README.md`); the adaptation is routine but A386548 is not covered there (its numerator is 1 − x², not 1 + x^u). Conjecture: Peter Bala (OEIS A386548, Jul 2025). Verification: `numerics/scripts/jk_ratio_form_and_closed_forms.py`, `sweep_2026-10-15.py`, `rereview_quad_A386548_identities.py` and `rereview_quad_A386548_congruences.py` (outputs in `numerics/out/`); review reports `verification/referee-reports/A386548-quadratic-tower-proof--nemotron-3-ultra-free.txt` and `verification/referee-reports/REREVIEW-A386548-and-A364175-A364178--fact-only-agent.txt`.

## 1. Statement and reformulation

a(n) = [x^n] ((1 − x)/(1 − x + x²))^n (A386548; a(0)=1, 0, −2, −3, 6, 25, 1, −147, …).

Since (1 + x)(1 − x + x²) = 1 + x³, we have (1 − x)/(1 − x + x²) = (1 − x²)/(1 + x³), hence

    a(N) = [x^N] (1 − x²)^N (1 + x³)^{−N} = Σ_{(j,k): 2j + 3k = N, 0≤j≤N, k≥0} (−1)^{j+k} C(N, j) C(N+k−1, k).        (1)

(Expand (1 − x²)^N = Σ_j (−1)^j C(N,j) x^{2j} and (1 + x³)^{−N} = Σ_k (−1)^k C(N+k−1,k) x^{3k}.) Formula (1) agrees with the OEIS formula a(n) = Σ_k (−1)^k C(n+k−1,k) C(n−k−1, n−2k) (checked numerically: `numerics/scripts/rereview_quad_A386548_identities.py` compares formula (1), the direct series coefficient and the OEIS formula for N ≤ 60, 0 failures; the earlier attribution of this check to `numerics/scripts/sweep_2026-10-15.py` was wrong — that script uses only the OEIS formula).

**Theorem.** For every prime p ≥ 5 and all integers n, r ≥ 1: a(n p^r) ≡ a(n p^{r−1}) (mod p^{2r}).

Numerics: the exponent 2r is attained (v_p = 2r exactly) for all tested (p, n, r) with p ∈ {5,7,11,13}, n ≤ 3, r ≤ 2; for p = 3 the congruence fails (v_3 = 1 at r = 1), consistent with the hypothesis p ≥ 5 (p ∤ 6).

## 2. Input: Jacobsthal–Kazandzidis, quotient form

(JK) For p ≥ 5 and integers A > B > 0:  v_p( C(pA, pB) / C(A, B) − 1 ) ≥ 3 + v_p(A) + v_p(B) + v_p(A−B), i.e. C(pA,pB)/C(A,B) ∈ 1 + p³AB(A−B)ℤ_p.

Numerical check: for p ∈ {5, 7, 11}, all 1 ≤ B < A ≤ 60 (1770 pairs per prime), v_p(C(pA,pB)/C(A,B) − 1) − (3 + v_p(A) + v_p(B) + v_p(A−B)) ≥ 0, with minimum 0 (`numerics/scripts/jk_ratio_form_and_closed_forms.py`). In the level form used in the case s ≥ r − 1 below (the case s < r − 1 uses the full asymmetric form): if p^s | A and p^s | B then C(pA,pB)/C(A,B) ≡ 1 (mod p^{3(s+1)}) (checked separately, min slack 0).

Two trivial facts: (T1) for p ∤ j, v_p(C(N, j)) ≥ v_p(N) (because C(N,j) = (N/j) C(N−1, j−1)); (T2) for p ∤ k, v_p(C(N+k−1, k)) ≥ v_p(N) (because C(N+k−1,k) = (N/k) C(N+k−1, k−1): indeed C(N+k−1,k)/C(N+k−1,k−1) = (k−1)!·N!/(k!·(N−1)!) = N/k). More generally v_p(C(N,j)) ≥ v_p(N) − v_p(j) and v_p(C(N+k−1,k)) ≥ v_p(N) − v_p(k).

## 3. Proof

Fix p ≥ 5. Write N = n p^r and M = N/p. Throughout, r is replaced by R := v_p(N) ≥ r (if p | n this is larger than r, and the conclusion modulo p^{2R} implies the one modulo p^{2r}); so below v_p(N) = R and v_p(M) = R − 1, and we write r for R to keep the notation of the Theorem. Convention: v_p(0) = +∞. Terms of (1) at level N are indexed by (j,k) with 2j + 3k = N.

*Synchronisation.* Since p ∤ 6 and p | N, the relation 2j + 3k = N gives p | j ⇔ p | k. Call (j,k) *unscaled* if p ∤ j (hence p ∤ k), *scaled* if j = pj', k = pk' (then 2j' + 3k' = M, so scaled pairs are in bijection with the level-M index set).

*Unscaled terms.* By (T1),(T2), v_p(C(N,j) C(N+k−1,k)) ≥ r + r = 2r. So every unscaled term is ≡ 0 (mod p^{2r}).

*Scaled terms.* Let (j,k) = (pj', pk') and put D = M + k'. Signs match: (−1)^{j+k} = (−1)^{p(j'+k')} = (−1)^{j'+k'} (p odd). Using C(pD − 1, pk') = (M/D)·C(pD, pk') and C(D − 1, k') = (M/D)·C(D, k') (both from C(X−1, Y) = ((X−Y)/X) C(X, Y) with X − Y = pM resp. M), the level-N term T_N(j') := C(pM, pj') C(pM + pk' − 1, pk') and the level-M term T_M(j') := C(M, j') C(M + k' − 1, k') satisfy

    T_N / T_M = Q_1 Q_2,   Q_1 = C(pM,pj')/C(M,j'),   Q_2 = C(pD,pk')/C(D,k')        (2)

(when T_M ≠ 0; boundary pairs with j' = 0 or k' = 0 give Q = 1 trivially since C(X,0) = 1 and C(pM−1,0) = 1 = C(M−1,0)).

Let s = min(v_p(j'), v_p(k')).

Case s < r − 1. From 2j' + 3k' = M with v_p(M) = r − 1 > s and p ∤ 6 (so v_p(2j') = v_p(j'), v_p(3k') = v_p(k')) we get v_p(j') = v_p(k') = s (otherwise the two valuations would differ and the sum would have valuation s < r−1). (Boundary pairs j' = 0 or k' = 0 have s = v_p(M) and fall into the next case.) Then v_p(M − j') = s, v_p(D) = v_p(M + k') = s, v_p(D − k') = v_p(M) = r − 1. By (JK): Q_1 ≡ 1 mod p^{3 + (r−1) + s + s}, Q_2 ≡ 1 mod p^{3 + s + s + (r−1)}, so Q_1Q_2 ≡ 1 (mod p^{r+2+2s}). Also v_p(T_M) ≥ 2(r − 1 − s) by the general forms of (T1),(T2) applied to C(M, j') and to C(D − 1, k') = C(M + k' − 1, k') (with v_p(M) = r − 1 and v_p(j') = v_p(k') = s). Hence v_p(T_N − T_M) = v_p(T_M) + v_p(Q_1Q_2 − 1) ≥ 2(r−1−s) + (r+2+2s) = 3r ≥ 2r.

Case s ≥ r − 1. Then p^{r−1} divides j', k', M, hence also M − j', D and D − k' = M. By (JK): Q_1, Q_2 ≡ 1 (mod p^{3r}), so T_N ≡ T_M (mod p^{3r}) (T_M is an integer).

*Conclusion.* a(N) − a(M) = Σ_{scaled} (T_N − T_M)·(sign) + Σ_{unscaled} (sign)·term ≡ 0 (mod p^{2r}). ∎

Remarks. (i) The scaled part even matches modulo p^{3r}; the exponent 2r comes only from the unscaled terms, which explains why the valuation is exactly 2r in the data (and why no p^{3r} tower holds). (ii) (Sketch, not written out.) The same proof should give, for u, v ≥ 1 and signs ε, δ ∈ {±1}, the quadratic tower for [x^{cN}] ((1 + εx^u)/(1 − δx^v))^N at all odd primes p ∤ uv; rbajaj5's family is ε = δ = 1 and A386548 is (u, v, ε, δ) = (2, 3, −1, −1). (iii) p = 3 is genuinely excluded: 3 | uv = 6 breaks the synchronisation.

## 5. References (citation confirmed 2026-10-15)
- (JK) is exactly Kazandzidis's theorem in the form stated and proved by A. Robert and M. Zuber, "The Kazandzidis supercongruences. A simple proof and an application", Rend. Sem. Mat. Univ. Padova 94 (1995) 235–243 (Numdam RSMUP_1995__94__235_0), abstract: for p ≥ 5 and n, k ≥ 0,

      C(np, kp) ≡ C(n, k)   mod  p³ · n · k · (n−k) · C(n,k) · ℤ_p,

  i.e. C(np,kp)/C(n,k) ∈ 1 + p³nk(n−k)ℤ_p, which is (JK) with A = n, B = k. (For p = 3 they give the modulus 3²nk(n−k)C(n,k)ℤ_3; not used.) Their proof uses the p-adic Gamma function via C(np,kp)/C(n,k) = Γ_p(np)/(Γ_p(kp)Γ_p((n−k)p)). Original sources: E. Jacobsthal (1952), G. S. Kazandzidis (1968, 1969); see also Granville (1997) and Meštrović's survey arXiv:1111.3057, eq. (37) and Remark 17.
