## The machine proof of A333096 (template for `proofs/A352275-u_m-family.md`)

The accepted Lean proof of Bala's conjecture on A333096 (general in m) lives in the results repository `epoch-research/LeanOpenProblems-results`, run `oeis-lite-200usd-sol-nk5wh4g0vh3546nm`, directory `oeis_333096_supercongruence_conjecture/Submission/`; other accepted runs for the same target are `oeis-lite-200usd-deep-ant-ewytt1ev01pbycd6`, `oeis-lite-200usd-deep-oai-fo3ygtloq79bdjph`, `oeis-lite-200usd-fable-i7s7n9q7v4emgjp7`, `oeis-lite-200usd-grok46-j6r2uynasidzofcj`, `oeis-open-lite-fable51-wm0v421z5ygi8f6b`, `oeis-open-lite-gpt6astra-37ly1phzfwj2ech4`. The accepted file is `Submission/Spec.lean` (2,546 lines); its main theorem `oeis_333096_supercongruence_conjecture (m : ℤ) (p : ℕ) …` is stated for every integer m (the other files of the submission folder, 5,356 lines in all, are working files). Architecture, as summarised in T. Adamczewski, arXiv:2608.11941, Appendix A: β((m+1)N, N) = [X^N] G(X)(1−X)^{−(m+1)N} with G = (1−2X)/((1−X)(1−X+X²)); a shift lemma p^{3(v+1)} | β(pS,pN) − β(S,N) when p^v | S, N; a Cartier fixed-point identity; the factorisation of X^p + (1−X)^p − 1; an antisymmetry cancellation; Legendre–Kummer and Stirling valuation bounds. The lemma `FNat_scale_supercongruence` of that proof is what `proofs/A352275-u_m-family.md` uses. The results repository has no licence file. Epoch AI gave permission to reuse its code (October 2026); `Submission/Spec.lean` of this run is included, adapted to Lean v4.35.0, as `lean/BalaProofs/EpochA333096.lean`, whose header lists every change.
